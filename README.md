# Сайт Марии — первая версия

Обновлённая страница, простой запрос на занятия и серверная отправка в Telegram. Фото, цены и контакт ожидают согласования. Вместо неподтверждённых отзывов и стажа использован нейтральный текст.

## Перед запуском

1. Отозвать прежний токен через BotFather: он был опубликован в исходном HTML и остаётся в истории Git и копии ai-lending-test. Удаление строки не отзывает токен.
2. Добавить реальное фото с разрешения Марии; сейчас используются инициалы.
3. Согласовать тексты, цены, Telegram и условия обработки заявок.

## Размещение с работающей формой

GitHub Pages исполняет только статические файлы. Для формы нужен сервер: здесь подготовлен Cloudflare Worker. Настройка отдельного хостинга ещё не выполнена.

Установить актуальный Wrangler через npm, затем выполнить `node prepare.mjs`: он копирует index.html, app.js и images/ в public. В public не должны попадать worker.mjs, конфигурация, документация или секреты. Файлы в корне сохранены для совместимости со статическим просмотром старого репозитория.

В wrangler.jsonc заполнить TELEGRAM_USERNAME (без @), PRICE_60 и PRICE_90. Пустые цены отображаются как «Стоимость уточним при знакомстве». Секреты TELEGRAM_BOT_TOKEN (новый токен) и TELEGRAM_CHAT_ID добавить через управление секретами Cloudflare или `wrangler secret put`. Не записывать токен в HTML, Git или чат.

Запустить `wrangler dev` для проверки, затем `wrangler deploy` для публикации. Rate limiter обязателен: без него или без секретов форма отключена. Ограничение — 3 обращения за 60 секунд на IP; оно снижает простой спам, но не заменяет полноценную антибот-защиту. При размещении нескольких Workers выбрать уникальный namespace_id для лимитера.

Проверить реальную заявку после настройки с согласия владельца Telegram. В этой версии реальная отправка не проверялась. Время занятий согласуется лично; автоматического бронирования нет.

## Локальная проверка

`node --test worker.test.mjs` — проверки входных данных, лимита и ответа Telegram с подменённым fetch. `node --check app.js` и `node --check worker.mjs` — синтаксис. При статическом просмотре без Worker форма честно сообщает о недоступности.
