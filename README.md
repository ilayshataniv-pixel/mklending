# Английский с Марией

Главная страница опубликована через GitHub Pages из корня ветки `main`. Посетитель выбирает время и отправляет заявку на этой странице. Cloudflare Worker проверяет данные и отправляет уведомление Марии. Вход и кабинет открываются на адресе Worker. Собственный домен не нужен.

## Локальная проверка

Из корня репозитория:

```sh
cd _worker
npm ci
npm test
npm run db:local
npm run dev
```

Откройте http://127.0.0.1:8787.

Для локальной проверки входа передайте `ACCOUNT_PEPPER` через `npm run dev -- --var ACCOUNT_PEPPER:<64 шестнадцатеричных символа>`. Используйте отдельное значение для разработки.

## Первый запуск на Cloudflare

1. Авторизуйтесь командой `npx wrangler login` из папки `_worker`.
2. Создайте D1 командой `npx wrangler d1 create mklending-schedule`. Укажите её идентификатор в привязке `DB` в `wrangler.jsonc`.
3. Примените схему командой `npx wrangler d1 execute mklending-schedule --remote --file=schema.sql`.
4. Выполните `npx wrangler deploy` и укажите полученный HTTPS-адрес Worker в `serviceOrigin` файла `pages-entry.js` в корне репозитория. Укажите адрес GitHub Pages без пути проекта в `PAGES_ORIGIN` в `wrangler.jsonc`.
5. Добавьте серверный секрет `ADMIN_KEY` длиной от 32 символов, чтобы заполнять расписание через `/admin.html`. Время занятий показывается по Иркутску.
6. Для регистрации и входа задайте секрет `ACCOUNT_PEPPER` из 32 случайных байтов в шестнадцатеричном виде. Сохраняйте это значение при обновлении сервера, чтобы ученики могли входить в существующие аккаунты.

### Кабинет ученика и домашние задания

Перед обновлением Worker примените схему `schema.sql` к существующей базе. Таблицы `lessons` и `homework` добавляются с сохранением аккаунтов и расписания.

Ученик открывает `/account.html` после входа. Здесь показаны назначенные занятия, ближайшее время по Иркутску, ссылка для подключения, история и домашние задания с текстом, материалами и сроком. Ученик ставит и снимает отметку о выполнении. API `/api/account/study` получает пользователя из серверной сессии и возвращает его данные. Назначенное занятие закрывает время в публичном расписании. После отмены применяется обычная доступность из расписания.

Для наполнения кабинетов подготовлены таблицы `lessons` и `homework`. Интерфейс преподавателя запланирован отдельным этапом.

### Восстановление пароля

Для существующей базы повторно примените `npx wrangler d1 execute mklending-schedule --remote --file=schema.sql`, чтобы создать таблицу одноразовых ссылок. Команда сохраняет существующие данные.

Подтвердите домен отправителя в [Unisender Go](https://godocs.unisender.ru/get-started) и включите отправку на адреса учеников. Задайте `RESET_FROM_EMAIL` (адрес отправителя), `RESET_ORIGIN` (HTTPS-адрес Worker без пути и завершающего слэша) и секрет `RESET_MAIL_API_KEY` в Cloudflare. После публикации запросите ссылку на свой тестовый аккаунт и проверьте вход с новым паролем. Для автоматической проверки с имитацией почты достаточно `npm test`.

### Telegram

Мария один раз открывает @mary_tech_bot и нажимает «Старт», чтобы бот мог присылать уведомления в её личный чат. Задайте секреты `TELEGRAM_BOT_TOKEN` (токен этого бота) и `TELEGRAM_CHAT_ID` (ID личного чата Марии) через Cloudflare. Используйте новый токен, если прежний публиковался в истории Git. Секреты не включаются в репозиторий. После настройки проверьте, что заявка с сайта доходит в личный чат Марии.
