# Английский с Марией

Главная страница опубликована через GitHub Pages из корня ветки `main`. Посетитель выбирает время и отправляет заявку на этой странице. Cloudflare Worker проверяет данные и отправляет уведомление Марии. Вход и кабинет открываются на адресе Worker. Собственный домен не нужен.

## Локальная проверка

Из корня репозитория:

```sh
cd _worker
npm ci
npm test
npm run db:local
npm run dev
```

Откройте http://127.0.0.1:8787.

## Первый запуск на Cloudflare

1. Авторизуйтесь командой `npx wrangler login` из папки `_worker`.
2. Создайте D1 командой `npx wrangler d1 create mklending-schedule`. Укажите её идентификатор в привязке `DB` в `wrangler.jsonc`.
3. Примените схему командой `npx wrangler d1 execute mklending-schedule --remote --file=schema.sql`.
4. Выполните `npx wrangler deploy` и укажите полученный HTTPS-адрес Worker в `serviceOrigin` файла `pages-entry.js` в корне репозитория. Укажите адрес GitHub Pages без пути проекта в `PAGES_ORIGIN` в `wrangler.jsonc`.
5. Добавьте серверный секрет `ADMIN_KEY` длиной от 32 символов, чтобы заполнять расписание через `/admin.html`. Время занятий показывается по Иркутску.

### Telegram

Мария один раз открывает @mary_tech_bot и нажимает «Старт», чтобы бот мог присылать уведомления в её личный чат. Задайте секреты `TELEGRAM_BOT_TOKEN` (токен этого бота) и `TELEGRAM_CHAT_ID` (ID личного чата Марии) через Cloudflare. Используйте новый токен, если прежний публиковался в истории Git. Секреты не включаются в репозиторий. После настройки проверьте, что заявка с сайта доходит в личный чат Марии.
